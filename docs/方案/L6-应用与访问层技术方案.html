使用 React Router、TanStack Query（服务状态）、轻量 Zustand（仅界面状态）、OpenAPI 生成 API client、i18next；管理员界面使用 Ant Design。公开页优先控制 bundle，不加载后台组件库。锁定依赖版本和 lockfile，SCA 扫描依赖漏洞。

环境变量仅公开非秘密配置：VITE_API_BASE_URL、VITE_OIDC_ISSUER、VITE_OIDC_CLIENT_ID、VITE_DPP_BASE_URL、VITE_DEFAULT_LOCALE。禁止将 client secret 或服务端密钥放入前端。

权限码仅作前端控件显示和导航过滤提示；每个 API 必须后端独立授权。菜单 action 与后端 scopes 建立同名映射表，在 CI 生成检查，新增 scope 必须有 owner。

4. 公开护照页与状态呈现

  • 手机扫码直达 /p/{publicCode}，显示当前有效 public projection、schema version、最后更新时间及适用语言。
  • 语言首发由用户选择/浏览器偏好决定；规划 en/de/fr/it/es/nl，首发语言和翻译责任需产品确认。字段代码不随翻译变化。
  • 状态页：已发布、已暂停/不可用、已失效/替代、未找到；未知和不可用对象显示统一文案，不暴露内部存在性/数据。
  • 受控内容只显示“需要授权”入口；认证后请求后端 restricted endpoint，不在 HTML/SSR hydration/cache 中带入完整敏感 JSON。
  • 二维码打印端/L5 resolver 提供 public URL；页面不自行从 SN 或设备 ID 查询护照。

5. 身份、租户与数据安全

  • OIDC 使用 Authorization Code + PKCE；access token 短时效，只存内存或安全 session 策略，不放 localStorage；refresh/revocation 依 IdP 能力配置。
  • 管理台每次 API 请求携带 bearer token；组织切换必须由后端授权，不能靠客户端传 org_id 伪造范围。
  • 服务端返回哪个 projection，客户端就渲染哪个；禁止前端拉全量数据后自行过滤。
  • React 输出默认转义；富文本/外部字段作为纯文本；CSP nonce/hash，禁用 unsafe-inline；链接使用安全 URL allowlist。
  • 公开页无第三方广告/分析 cookie；日志不记录完整 publicCode、token、护照数据。公开解析加 WAF/限流由边缘/L5 实施。
  • HSTS、frame-ancestors 'none'、X-Content-Type-Options、Referrer-Policy；CORS 在 API gateway 明确 allowlist。

6. API 客户端与错误处理

通过后端 OpenAPI contract 生成 TypeScript 客户端；不手写重复 API 类型。公共错误模型：code,message,traceId,fieldErrors,retryable。UI 按 error code 映射可操作提示，绝不向用户暴露堆栈或内部字段。

  • 401：尝试一次静默 re-auth；失败转登录；避免无限重试。
  • 403：显示权限不足/申请授权入口；不推断资源存在性。
  • 409：提示数据版本冲突并刷新，不自动覆盖。
  • 429/5xx：指数退避、最多一次自动重试非幂等写入除外；展示 traceId 以便支持排查。
  • 上传使用进度和取消；用户离开页面后由服务器任务继续，重新进入可恢复查询。

7. 可访问性、性能与部署

  • 目标 WCAG 2.1 AA：键盘可操作、语义标题/表格、焦点状态、对比度、表单错误关联和屏幕阅读器标签。
  • 目标性能：公众扫码页面 4G 下 LCP < 2.5s，CLS < 0.1；压缩/按路由拆包，首屏只请求 public projection，设置静态资源长期缓存和 HTML 短缓存。
  • 管理台可采用 Kubernetes Nginx 静态容器/CDN；公开页同样部署静态容器/CDN。严禁将 SSR 公共缓存用于受控页。
  • 构建阶段依环境注入 public config；CSP 与 API/CORS 域名配置经环境发布。回滚用不可变构建产物版本。
  • 国际化翻译从消息目录加载；日期/数字/单位使用 locale formatting，字段 schema code 和原始值仍保持规范化。

8. 测试与开发任务

  1. Vitest + React Testing Library：路由权限呈现、表单校验、错误码映射、公开/受控投影组件。
  2. Playwright：OIDC PKCE mock 登录、导入→错误修复→审核→发布流程、匿名扫码公开访问、受限数据授权拒绝/通过、暂停缓存页行为。
  3. 安全测试：无 token 页面不会请求 restricted API；API 401/403/429 处理；DOM 中受控字段/PII 检查；CSP 头及 XSS payload。
  4. 可访问性扫描及键盘操作测试；多语言缺失 key 构建失败；移动设备 viewport 截图。
  5. OpenAPI TS client CI 生成差异检查；依赖 SCA、静态扫描、构建产物 secret scan。

任务：初始化 workspace/routes/API client → OIDC PKCE 与 action map → 管理工作台骨架和数据页面 → 公开护照页 → i18n/a11y/CSP → Playwright/安全/性能验收 → K8s 部署配置。
